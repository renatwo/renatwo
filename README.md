🏔️ Highland Automation — meu projeto principal

SaaS multiempresa que fiz do zero para barbearias, clínicas de estética, salões e consultórios odontológicos: agente de IA que responde e agenda pelo WhatsApp, mais site profissional para o negócio. Hoje em fase de recrutamento de beta testers.

O núcleo do produto é a Liza, o bot de agendamento. Já passou por várias versões de workflow (v23 a v25) resolvendo problemas reais de produção: alucinação do modelo, corrupção de system prompt, timeouts de HTTP faltando, falhas de tool-calling. Arquitetura multi-tenant, com 8 sub-workflows especializados rodando em n8n self-hosted numa VPS (Hostinger + EasyPanel/Docker Swarm).
