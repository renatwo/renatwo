Quem sou

Passei mais de 10 anos em vendas B2B, logística e administração — hoje ainda atuo em vendas B2B na Danny, empresa de EPI. Em 2025 comecei a construir a transição pra tecnologia: entrei na PUC-PR pra estudar IA Aplicada e comecei a construir produtos de verdade em vez de só estudar teoria.

Não sou dev de formação. Sou alguém que aprendeu a construir agentes de IA e automações porque tinha um problema real pra resolver (negócios locais perdendo agendamentos por não responder o WhatsApp a tempo) — e isso virou a Highland Automation.

<br>
🏔️ Highland Automation — meu projeto principal

SaaS multiempresa que fiz do zero para barbearias, clínicas de estética, salões e consultórios odontológicos: agente de IA que responde e agenda pelo WhatsApp, mais site profissional para o negócio. Hoje em fase de recrutamento de beta testers.

O núcleo do produto é a Liza, o bot de agendamento. Ela já passou por várias versões de workflow (v23 a v25) resolvendo problemas reais de produção: alucinação do modelo, corrupção de system prompt, timeouts de HTTP faltando, falhas de tool-calling. A arquitetura é multi-tenant, com 8 sub-workflows especializados rodando em n8n self-hosted numa VPS (Hostinger + EasyPanel/Docker Swarm).

Stack em produção: n8n · Supabase · Evolution API · Claude API · Vertex AI/Gemini · Python · Lovable

Além do produto, montei sozinho os Custom GPTs de apoio ao negócio (marketing, prospecção B2B, estratégia de conteúdo) e explorei a Instagram Graph API para o processo de onboarding via Meta App Review.
